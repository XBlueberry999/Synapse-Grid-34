# Security / Keamanan

Do not publish exploit details, credentials, backups or private customer data in a public issue. Contact the repository maintainer privately through a channel they designate; no reporting address or response-time promise has been invented here. If no channel exists, ask for a private channel without including the vulnerability. Rotate exposed secrets and retain a recovery backup. No independent full security audit has been completed.

Jangan kirim exploit, kredensial, backup atau data privat ke issue publik. Hubungi maintainer melalui kanal privat yang mereka sediakan. Jika belum ada, minta kanal privat tanpa menyertakan kerentanan. Rotasi secret yang bocor dan siapkan backup pemulihan. Belum ada audit keamanan independen menyeluruh.
